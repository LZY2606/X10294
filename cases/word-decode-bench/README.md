# 字路译码台：ARINC 429 标签、奇偶与速率分段证据

本目录是**专门的离线案例包**，不是通用表格。它服务于航电数据小组的工作流：导入时间戳与 32 位原始字、通道配置与标签字典，审阅字序、速率分段与工程值解释。

## 叙事主线（不拆成互不相关的按钮）

1. **初始导入与基线核对**：审阅者先核对原位序列、接收时间、通道、奇偶结果、label、SDI、SSM、数据域和字典版本均保留（`B0-baseline`，材料 `MAT-BENCH` r1，字典 `dict-v1`）。
2. **边界组合反例**：对单一直接来源做最小改动，检验影响是否被限制在正确范围：
   - 位序反转（`B1-bit-reverse`，整字 32 位反转，针对 `W02`）
   - 奇偶错误（`B2-parity-error`，翻转 `W02` 的 bit32）
   - 八进制 label（标签始终以八进制展示，如 `313`/`466`；展示切换不改底层位，见 `W15=001`、`W16=377`）
   - BNR 负值（`B3-bnr-negative`，`W05` 改为二补数 -0.5 g；基线 `W06` 亦为负值）
   - BCD 非法数字（`B4-bcd-illegal`，`W08` 分钟低位塞入 0xC；基线 `W10` 同情形）
   - 速率切换（`B5-rate-switch`，CH-B 10Hz→缺口→20Hz；改候选集合/缺口倍数只影响速率派生层）
   - SSM 无效状态（`B6-ssm-invalid`，`W02` 置 SSM=10 NO_COMPUTED_DATA；基线 `W13` 同情形）
3. **局部依赖的源数据修订**（`B7-source-fix-local`）：材料 r2 只替换 `W02`，失效范围只覆盖该字解释与 313 标签聚合，旧分支 `B2` 及其原始字节继续可读。
4. **参数修订**（`B8-dict-v2`）：字典升级仅把 label 314 从 BNR 改判为 discrete，失效范围严格限制在该标签；313/466/416 结论不变。
5. **互相冲突的人工决定**（步骤 9）：两名审阅者对 CH-B 第二段速率候选分别接受 20Hz 与 10Hz，后提交者收到版本冲突与双方差异。

## 判断依据（机器可读）

`replay.json` 的 `rationaleRules` 是机器可读事件依据，固定规则：

- `R-octal-display`：label 的八进制展示不改变底层位。
- `R-dict-version`：BNR/BCD/discrete 解释由字典版本决定。
- `R-rate-segments`：速率变化与采集缺口保留分段候选；无法唯一决定时保留全部合法候选。
- `R-bad-parity`：坏奇偶字不进入聚合值。

被采纳与未被采纳的候选都会保留（`adopted`/`rejected`/`pending` 状态），任一裁定可撤销并恢复前一分支。

## 量纲与坐标基准

- 空速：`kn`，指示空速 ISA；法向加速度：`g`，机体法向轴；UTC 时间：`HHMM@UTC`；discrete 带“bit=1 表示有效/放下”坐标基准。
- 无法转换的值（BCD 非法、SSM 无效、奇偶错误、字典未命中）留在原位置并附诊断，不为画图丢弃。

## 文件

- `manifest.json`：案例清单、基线引用、速率候选参数。
- `channels.json`：三路通道配置（标准位序 / 速率演示 / 整字反序采集器）。
- `dictionaries.json`：`dict-v1`、`dict-v2` 两版标签字典。
- `baseline-words.json`：36 个基线字（含显式 `word32Hex` 原始表示）。
- `replay.json`：重放步骤、影响范围断言与规则依据。
